# Unitrack: University Academic Operating System 📚

A student-focused academic operating system for managing semesters, credit hours, recurring timetables, tasks, and GPA.

## Technology
- Next.js 15 and React 19
- TypeScript
- Prisma ORM
- Tailwind CSS
